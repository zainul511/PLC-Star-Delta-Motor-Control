# PLC-Based Automatic Star-Delta Motor Control System

## Overview

This project implements an automatic star-delta motor starting and connection switching system using a Siemens S7-1500 PLC programmed in TIA Portal.

## Features

- Automatic switching from star to delta connection using timer-based control.
- Interlocking logic to prevent simultaneous activation of star and delta contactors.
- Program simulation and testing using Siemens PLCSIM.

## Tools Used

- Siemens TIA Portal
- Siemens PLCSIM

## Project Files

- **Project ZIP:** PLC project files.
- **Screenshots:** PLC program and simulation results.
- **Demo Video:** Demonstration of the simulated motor control sequence.

## Objective

To develop and simulate a PLC-based motor control system demonstrating industrial motor starting, timer control, and contactor interlocking.
